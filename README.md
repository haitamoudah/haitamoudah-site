   # haitamoudah.com

   personal site. one page, continuous scroll, 3d wireframe background.

   ## stack
   next.js 16, react 19, typescript, tailwind css 4, three.js (react-three-fiber), gsap.

   ## how it's built
   developed with claude code. project rules live in `CLAUDE.md`. a custom subagent,
   `.claude/agents/design-reviewer.md`, screenshots the running site at three breakpoints
   with playwright and lists defects against the visual reference after every visual change.
